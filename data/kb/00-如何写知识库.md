# 如何写知识库文档

本目录下的 `.md` / `.txt` 会被自动切块建索引（BM25），供助手检索。不需要改代码，放进文件即可。

## 写作原则

1. **一篇解决一类问题**：标题写「现象 / 模块 / 流程」，不要写「杂项」。
2. **开头三行给结论**：现象是什么、原因是什么、怎么处理。助手优先命中开头。
3. **命令与参数写全**：路径、参数名、取值格式都写完整，不要写「按需配置」。
4. **贴日志只贴关键行**：错误码、回执原文保留英文，不要整段粘贴。
5. **不要放真实数据**：单号、手机号、身份证、卡号一律用占位符（如 `ORDER_ID`、`138****0001`）。

## 命名建议

```
<模块>-<主题>.md          例：gateway-timeout.md
<现象>-排查.md             例：502-排查.md
流程-<业务>.md             例：流程-发布审批.md
```

## 不需要写 front-matter

系统不解析 YAML 头，标题用一级标题 `#` 即可。子目录会被递归扫描，可用于分层。
